# 2026-11-23

## Claude Code 模式子进程权限问题（1.1.2）

- 现象：经 Proxy Harbor 接管启动 Claude 后，Code 模式无法打开；Claude 日志 `Claude Code process exited with code 5`、`git --version code 5`、`wsl.exe --list exited 5`。
- 根因：`native/session/claude_takeover.c` 的调试监督把镜像不是 `Claude.exe` 的子进程全部以 `ERROR_ACCESS_DENIED(5)` 终止；每次都只记录到 `reg.exe`。
- 修复：同用户 SID 的后代放行并写入 `takeover-components.log`；已退出子进程不再误判；`takeover-component.json` 改覆盖写；`guardian.c` 当前用户模式入站规则恢复 127.0.0.1 例外。
- 保护边界：WFP 固定出口仍只覆盖 Claude.exe；Code 模式后代走 v2rayN 全局/TUN。
- 产物：`app/proxy-harbor/bin/release-1.1.2/Proxy-Harbor-1.1.2-win-x64-setup.exe`，守护 SHA-256 `237983dc…4fb7e6`。Go 测试、前端单测通过；真实 Code 模式待用户确认。
- 构建注意：本机 vcvars64 依赖的 `reg.exe` 被安全策略拦截，需先手动设置 MSVC 的 INCLUDE/LIB/PATH 再运行 `scripts/release.ps1`。
