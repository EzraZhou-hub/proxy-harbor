# 2026-11-24

## 托盘常驻（1.2.0）

用户诉求：安装后程序要长时间驻留，关闭窗口后台不退出，托盘里保留图标。

根因：`native/session/guardian.c` 的监控循环每 200ms 检查桌面进程 `parent` 句柄，桌面一退出就写 `desktop_exited` 并结束受保护会话。所以“关窗口即断保护”是设计行为，不能只改窗口层不解释。

实现（只动桌面进程生命周期，未改守护程序/WFP/DNS/出口核验）：

- 新增 `app/proxy-harbor/tray_desktop.go`（`!server`）与 `tray_server.go`（空实现）。
- `RegisterHook(events.Common.WindowClosing)` → `event.Cancel()` + `window.Hide()`；Wails 先发 `Windows.WindowClosing(1212)` 再由 mapping 转 `Common.WindowClosing(1030)`，钩子在内部销毁监听器之前，窗口对象保留。
- 托盘菜单：打开主界面 / 状态（3s 刷新，保护中带出口 IP）/ 登录时启动（`Autostart` 写 HKCU Run，带 `--tray`）/ 退出。会话进行中退出先弹确认，默认「继续保护」。
- `main.go` 增加 `trayArgument = "--tray"` 与 `Hidden: startHidden`；`instance_desktop.go` 二次启动走 `residentApp.show()`。
- `session.Runtime.Refresh()`：托盘不能复用构造时选定会话目录的实例，每次重新 `selectSession()`。
- 前端 `Workspace.vue` 监听 `tray:visibility` + `visibilitychange`，隐藏时暂停 1s 轮询，显示时补读。
- 图标 `build/tray.ico`（16-64 多尺寸，盾牌+横杠）；生成器在 `.cache/trayicon`（未入库）。
- NSIS：新增 `CheckRunning`/`un.CheckRunning`（追加打开 exe 探测占用，确认后 `taskkill /F`）、卸载删 `HKCU\...\Run\proxy-harbor`；版本 1.2.0。

验证：`go vet`、`go test ./...`、`vue-tsc`、4 项草稿回归、7 项 Playwright（需先重建 `-tags server` 宿主，否则测的是旧前端嵌入）、`wails3 build` 全通过；真实二进制冒烟确认 `WM_CLOSE` 后进程存活 + 窗口句柄归零、二次启动唤起原句柄、`--tray` 无可见窗口；`w32.CreateSmallHIconFromImage` 接受该 ICO。

未验证：托盘图标/菜单实际显示、登录启动、安装包（本机无 `makensis`，需装 NSIS 后跑 `scripts/release.ps1`）。

注意事项：`wails3 build` 首次运行会用 `generate:icons` 重写 `build/appicon.png`、`windows/icon.ico`、`darwin/icons.icns`；本次已还原这三个二进制，避免混入无关改动。

## 1.2.0 安装包

`scripts/release.ps1` 跑不通：`build-guardian.ps1` 生成的 `compile-guardian.cmd` 会 `call vcvars64.bat`，其中的 `reg.exe` 被本机安全策略黑名单硬拦截（不可绕过）。两次失败分别为「无匹配守护程序」和「Session guardian build failed」。

手工装配（其余步骤与 release.ps1 一致）：

1. 先把 `bin/release-1.1.3/proxy-harbor-guardian.exe`（SHA-256 与 `approved_guardian.json` 一致）放进 `bin/release-1.2.0/`，否则 `-UsePinnedGuardian` 的候选列表不含历史 release 目录。
2. `wails3 build BIN_DIR=bin\release-1.2.0`。
3. 复制 1.1.3 的 `proxy-harbor-session-inventory.exe`（构建于 11-23 13:13，source 最后改动 11-19 11:54，之后未改）。
4. `wails3 generate webview2bootstrapper -dir build\windows\nsis`。
5. NSIS 3.10 便携版（下载 zip 解压到 `.cache/nsis/nsis-3.10`，本机未安装），用与 release.ps1 相同 defines 编译 `project.nsi`，exit 0。
