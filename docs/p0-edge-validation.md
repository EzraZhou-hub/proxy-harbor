2026-11-14：Edge 已直接通过项目 SOCKS5 中转访问公网；固定身份的 TCP 阻断、转发器退出后保留阻断、显式解除后恢复等受控检查通过。完整保护仍未验收，桌面保护不可开启。

## 实验范围与结果

最终包：`.local/p0/sandbox/20261114-042617-8f4b19/`。来宾 `787d055b-9562-46bc-a8fb-23ddce3584ad`，Edge `157.0.4341.46`。输入经清单摘要核对，系统规则只在来宾执行；网卡、剪贴板、音视频、打印和 vGPU 关闭。使用全新浏览器数据目录，没有导入账户或操作宿主浏览器/Codex/Claude。

最终链路：Edge 原生 SOCKS5 → 项目 `Relay` / `TransportGate` → 来宾临时文件通道 → 宿主 HTTP `127.0.0.1:10808` → 现有 Xray 客户端。文件通道仅是保持来宾网卡关闭时的实验条件，没有宿主对外监听；项目转发器仍使用不超过五分钟的独立许可，没有自动续期。

用户确认本轮临时切换客户端到全局路由，节点和本地端口不变。该信息按用户报告记录，没有读取真实节点配置或凭据，也没有替用户修改全局代理。此前规则模式样本与本轮条件不同，不能将结果变化全部归因于路由模式。

## 修复的误判与移除的临时组件

旧采集等待页面完成，或在 12 秒就强制捕获，会把未完成导航报告为空页面。全局模式下网络记录显示目标 HTTP 200 和正文在该窗口之后到达；这证明至少部分“失败”是采集时机问题，不足以判定 SOCKS5 或规则路由失效。

采集现在给浏览器 30 秒，外层 40 秒；Google 独立复核为 45 秒/55 秒，最多两个新连接尝试，实际首个尝试成功。使用有界 DOM/截图捕获，依据 [Chromium 官方命令说明](https://developer.chrome.com/docs/automation-and-testing/headless-cli)。没有禁用 TLS 校验、浏览器沙箱或安全策略。较长窗口不保证所有网站、所有资源和每次连接都成功。

保留了有实际依赖的内部 SOCKS5，移除了排查时增加的 `edge-http-adapter.mjs` 及其构建/运行引用。Edge 最终直接使用项目 SOCKS5 入口；历史 HTTP 转换层实验及失败包保留于 `.local/p0/sandbox/`，不进入当前链路。HTTP、HTTPS、SOCKS5 上游选项不在本轮无依据删减。

早期包 `20261113-145801-3ad3b6` 保留了空输出处理错误、服务账户无法正常启动浏览器、短时采集超时等记录，这些没有计为兼容性通过。服务账户样本只作失败排查，最终验证在来宾现有交互用户下执行。

## 独立规则边界

新增 `P0_EDGE_GUARD` 构建使用单独子层和四个规则键，只匹配来宾固定 Edge 程序路径，拒绝任意应用路径输入。修改动作要求固定来宾工作目录、标记和工具自身路径；所有实际安装/删除均在来宾中执行。四条持久规则仅放行 IPv4 TCP 到项目指定回环端口，阻断其他 IPv4 地址/协议/端口和全部 IPv6 连接。

来宾网卡关闭不能单独证明项目防直连有效，因此采用安装前、安装后、移除后可达性对照，且同一端点有其他程序的正向控制。这里的 IPv6 证据为受控 TCP 回环，不是公网 IPv6 验收。

完整系统 DNS、共享服务、DoH/辅助程序、实际 UDP 外发、公网 IPv6、入口 PID 绑定/端口重占、任意应用透明接管、长期稳定性和开机最早阶段仍未验收。匿名页面 NetLog 中的 DNS 尝试/错误不等于已经证明 DNS 报文泄漏或阻断成功。完整协议/系统回归仍以此前 `20261113-105143-22cf59` 包为准，本轮没有重跑该全量包。

## SOCKS5 与用户节点协议

SOCKS5 在当前 P0 中是本地中转接口，`internal/engine/relay.go`、透明接管实验和 DNS 实验仍依赖它。它不是要求用户额外搭建的远程节点。当前用户提供的入口为 HTTP `127.0.0.1:10808`，VLESS / XHTTP / REALITY 仍由已有客户端处理；项目没有原生实现这些节点协议。

将请求交给本地客户端不代表一定经远端节点：Xray 可按路由规则选择不同出站，见 [官方路由说明](https://xtls.github.io/config/routing.html)。最终产品需要在用户日常规则模式下验证；本轮全局只是排查条件，测试结束可以恢复规则模式。

本轮未购买或新增商业 SDK，没有加载驱动或重启任何机器。详细汇总和源码摘要见 `.local/p0/edge-validation.json`，清理记录见 `.local/p0/host-cleanup-check.json`。
