# 桌面基础框架交付记录

日期：2026-11-10。产品暂名 Proxy Harbor，版本 0.1.0。

用户在环境准备完成后要求先建立基础框架。本次交付是桌面程序和模块骨架；不把它记为 P0 原生内核验收完成。

## 2026-11-11 基础可靠性修复

- 同一数据目录的原生桌面程序启用单实例，重复启动会显示并聚焦已有窗口。独立测试服务允许多进程，但保存使用进程间锁和原文件摘要检查，过期配置只能重新读取后再保存。
- 前端合并后台快照时保留未保存的应用路径；保存某一项只同步该项，保存期间再次输入的草稿也会保留。
- 配置加载失败后窗口正常显示恢复页，禁止普通配置写入；支持重新读取、打开配置目录，以及用户确认后的备份并重置。原始内容完整写入、同步并关闭备份后，才替换原配置；文件变化会拒绝重置并要求重新读取。
- 开发阶段暂停一切 Claude 测试，等待项目最后用户明确通知。现有测试的应用操作改为 Codex；多条目草稿测试使用通用模型数据。占位 EXE 不执行。
- `build.ps1 -Check` 增加前端草稿回归，Go 测试范围包含桌面单实例选项。

这些修复不启用代理内核、应用启动或系统网络变更。

本次验证通过：`go test ./...`、`go vet ./...`、前端类型检查、4 项通用草稿回归、5 项真实 Go 后台 + Edge 界面集成测试，以及 Windows 桌面和测试服务构建。新增恢复页已在 960×680 窗口渲染检查，无横向溢出。多进程测试确认旧快照不能覆盖配置，重新读取后两份新增内容均能保留。

应用条目测试仅操作 Codex 和临时占位文件；未启动或测试真实目标应用。原生窗口聚焦回调与打开资源管理器的操作已编译接通，尚未通过自动化驱动原生桌面验证。

第一项 P0 进行中：2026-11-13 完整离线回归中，受控入口/持续阻断的 6 组、168 条观测和透明接管的 6 组、282 条观测通过；规则已清理，来宾已停止，宿主机三组实验规则均为 0。现有本地 HTTP 入口的真实 HTTPS 出口检查也通过。任意应用透明接管、完整系统 DNS 覆盖、公网 IPv6/UDP 及完整开机顺序等仍待验收，桌面保护仍不可开启。见 [当前进度与边界](p0-transparent-progress.md)及 [P0 验证记录](p0-validation.md)。

## 可运行的部分

- Wails 3.1.0 + Go + Vue 3 / TypeScript / Vite 桌面项目，前后端生成类型绑定。
- 连接概览、应用管理、代理配置、诊断与日志页面。
- HTTP、HTTPS、SOCKS5 代理入口的新增、编辑、选择、删除及本地保存，输入检查在后端执行。
- Claude/Codex 路径登记，Windows EXE 文件选择、存在性检查；不会启动目标程序。
- 本机平台、主机名称、活动接口及地址只读采集；不进行外部 IP、DNS 或 STUN 探测。
- JSON 报告导出、当前会话操作日志、保存失败提示。
- 内核适配接口、传输无关控制接口、配置持久化边界，为后续 Windows 服务与 Named Pipe 留出替换位置。

## 当前明确不可用的部分

真实保护内核、WFP/WinDivert 策略、DNS 接管、UDP 转发、应用启动、辅助进程覆盖、凭据存储、SQLite 历史、独立 Windows 服务、Named Pipe 与托盘驻留尚未实现。

当前控制实现在桌面进程内运行；窗口关闭即退出此基础版。未来存在受保护会话时，才按开发计划加入托盘和安全退出状态机。

所有内核能力为未接入；保护状态为 unavailable，CanStart=false；出口、DNS、IPv6、UDP 检测均为 not_run。后台 StartProtection 即使被直接调用，也返回明确错误，不执行任何网络或进程操作。

代理表单暂不接受或保存密码；后端拒绝把含协议/账号/密码的 URL 当成 Host 保存。认证能力需要后续安全凭据模块接入，入口配置不等于可用的已认证连接。

## 数据与进程边界

正式配置默认在 `%APPDATA%\ProxyHarbor\config.json`，只有保存时才创建；可以用 PROXY_HARBOR_DATA_DIR 覆盖。文件采用同目录临时文件、同步、Windows 替换写入，损坏/不支持配置不会被启动流程覆盖。

测试使用 `.local/e2e-*` 隔离目录及仅用于验证路径的 EXE 占位文件。占位文件不会执行。测试服务仅监听 127.0.0.1:19345，测试完成后退出；不是已安装的 Windows 服务。

JSON 导出包括本机地址和程序路径，未包含密码。界面通过真实 Go 绑定加载数据；无浏览器 localStorage 模拟后端。

## 验证记录

已通过：

1. Vue/TypeScript 类型检查与 Vite 生产构建。
2. Go 核心测试：三种入口配置、多次替换保存、重启加载、删除当前代理、应用路径保存。
3. 保存失败时内存配置不变；损坏/不支持配置保留原文件；含凭据地址拒绝落盘；配置不能自行声明已验证。
4. 保护启动边界：即使测试适配器宣称所有能力都具备，当前框架也不会调用它启用保护。
5. 真实 Go 服务 + 无头 Edge 集成：四页导航、三种入口保存、编辑、刷新保留、删除、无效输入、应用路径登记、本机信息刷新、报告下载、保护按钮禁用。
6. 集成测试期间没有页面级外部网络请求、没有 JavaScript 运行错误；960px 宽度未出现横向溢出。
7. Windows 原生桌面 EXE 构建，包含普通权限清单与产品图标。

界面交互通过 Wails server 构建和真实绑定进行验证；原生 WebView2 窗口的交互与文件选择对话框尚未自动化验证。没有把通过编译或界面测试解释为代理/防泄露测试通过。
