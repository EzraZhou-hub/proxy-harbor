## 工作方式

- 先检查既有代理及 HTTPS 公网 IPv4 出口，再安装并核对限制，最后启动浏览器。后续持续检查代理进程、监听端口、规则、监控状态及代理出口。
- 受管身份只允许 TCP 连接指定回环代理入口。IPv6、UDP、其他地址和端口被阻断。普通子程序继承同一身份；不能靠改名或换 EXE 路径绕过已安装的身份约束。
- 代理端口同时限制程序身份和用户身份，避免代理退出后被其他程序冒用。异常时先保持阻断，再结束本次 Job 及核对属于同一临时身份的进程。身份和进程清理未确认时保留限制。
- 守护程序异常退出时，Job 结束其进程；规则持久保留。独立恢复必须核对身份、记录及实际规则；损坏记录、错误端口和仍存活的身份不能被静默解除。
- 候选 Runtime 校验固定守护程序 SHA-256；桌面另有显式关闭的准入锁，指纹匹配不代表桌面获准开启。状态同时核对 PID 与创建时间。
