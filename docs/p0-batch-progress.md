## 用户确认的目标

指定应用经电脑现有的 IPv4 代理出口联网。应用不能绕过入口直连，代理失效、转发器退出时继续阻断。IPv6 和 UDP 首版按阻断处理；不要求用户购买额外账户、IPv6 节点或提供 IPv6 测试环境。

用户接受全局路由或 TUN。本轮最后已手动确认 v2rayN 全局、原节点及 HTTP `127.0.0.1:10808` 不变，未开启 TUN。只读识别到入口所属进程为 `xray.exe`、父进程为 `v2rayN.exe`；未读取它们的节点配置、凭据或进程命令行。VLESS / XHTTP / REALITY 仍由现有客户端处理。

本项目首先约束连接路径。正常保护期间就禁止受管程序绕过代理，不依赖发生直连后再查询 IP。现有代理客户端本身也须维持所确认的代理路由；规则模式的 HTTP 入口可能被客户端分流到 DIRECT，仅看到本地入口连接成功不能证明最终代理出口。Xray 的行为依据 [官方路由说明](https://xtls.github.io/config/routing.html)。

## 解决的组合问题

### 系统 DNS 不能只靠 EXE 路径规则

来宾对 `.p0-dns-audit.invalid` 临时配置唯一 NRPT 观察规则，指向受控 UDP/TCP DNS 端点。它是测试环境布置，不是产品的 DNS 保护方案，结束后按精确所有者、命名空间与服务器核对并删除；未修改宿主 DNS。

六种默认解析调用先验证未限制程序能得到受控 A 应答。随后七种仅加 EXE 规则的调用仍由 Dnscache 代发，原缺口继续如实记录。零网络能力 AppContainer 下对应冷请求被拒绝，指定 SOCKS5 代理仍能工作。

缓存场景先种入 60 秒记录，再由普通程序的缓存专用请求证明缓存确实已热；容器内缓存请求返回拒绝，未产生额外 DNS 流量。拒绝查询不计为远端解析成功。合成 IPv4 映射与后续原始域名代理连接是另一组独立正向证据。

该结果限于所列调用和固定临时身份，尚不能声称所有共享服务、DoH/DoT、多播及任意 RPC 已获完整覆盖。AAAA / TXT / HTTPS 原生记录类型、部分扩展异步和原始 DNS 模式仍明确拒绝，不能写成已经支持。

### 隔离身份与透明钩子的兼容

原候选的全局命名管道在 AppContainer 内创建失败，已将实验构建改为 `LOCAL` 命名空间，管道 DACL 授权当前用户和本次具体包 SID。没有给所有容器统一增加权限。

钩子需要持有指定转发器的存活及映像身份句柄。来宾仅临时给本次 SID 增加该固定进程的 `SYNCHRONIZE | PROCESS_QUERY_LIMITED_INFORMATION`；子孙程序结束后恢复并逐字节核对原 DACL。未授予写入、注入或终止权限，宿主未改变进程 DACL。

AppContainer 中 `GetExtendedTcpTable` 实测返回 5，因此原入口 PID 查询会拒绝正常连接。新增可选的本地入口证明：32 字节随机挑战，转发器用仅在内存中的 32 字节临时密钥计算 HMAC-SHA256；钩子验证后才发送 SOCKS5。错误密钥、旧挑战应答重放、截断和未提供证明均有负向测试。没有删除普通模式的 PID 校验，也没有用一次 SOCKS 响应当作身份认证。

该证明同时保留固定映像进程句柄存活检查、四条入口端口保留规则及父/辅助程序的八条出站限制。证明是本地中转内部协议，不是要求用户改用新的节点协议；密钥不从真实节点读取、不写到命令行或报告。普通 Edge 原生 SOCKS 模式保持原协议。

### 取消调试回环例外的最终候选

最终 `appcontainer-wfp` 模式保留零网络能力，只在来宾为本次临时 SID 安装六条 WFP 规则：四条独立拒绝规则限制地址、协议、端口及全部 IPv6；一条许可精确匹配该 SID、IPv4 `127.0.0.1`、TCP 和中转端口；另一条接收许可只匹配固定中转程序、回环地址和同一端口。许可使用明确的高优先级和 action-right 设置，其仲裁语义见 [微软说明](https://learn.microsoft.com/en-us/windows/win32/fwp/filter-arbitration)。没有给容器增加 Internet 能力。

恢复记录在规则安装前写入，包含本次 SID、端口和所有者。结束时先结束受控进程，再逐条匹配规则键、SID、身份、地址/协议/端口、动作及归属信息，事务删除六条规则；另一个进程只读核对项目键为零。文件和进程 DACL 也恢复并核对后才删除临时身份。

首轮 `.local/p0/sandbox/20261114-064850-2142b7/` 的代理通信成功，但清理校验拒绝了 BFE 自动添加的 `FWPM_FILTER_FLAG_INDEXED`，六条规则未删，报告明确为失败；该来宾已停止并丢弃，不把丢弃算作其显式清理通过。后续只兼容这一索引性能标志，其他状态标志仍严格核对，依据 [微软字段定义](https://learn.microsoft.com/en-us/windows/win32/api/fwpmtypes/ns-fwpmtypes-fwpm_filter0)。最终包所有场景的显式清理及独立查询均通过。旧调试模式仅保留为历史对照，不是本轮真实 HTTPS 的选用方式。

### 公网 UDP 的实际阻断证据

首次联网补测中，受管 UDP 请求超时，尚不能单独证明本项目进行了丢弃。后续新增来宾专用的 `p0-net-events.exe`，只启动固定探针访问固定公网端点，并按时间、应用身份、协议、目标和本项目四条规则的运行时 ID 匹配 WFP 丢包事件。

实际匹配到一次项目过滤器丢包，诊断采集配置恢复并核对成功。报告只输出匹配元数据，不采集账号、认证流量或其他应用载荷。观察 API 依据 [FwpmNetEventEnum0](https://learn.microsoft.com/en-us/windows/win32/api/fwpmu/nf-fwpmu-fwpmneteventenum0)、[采集选项](https://learn.microsoft.com/en-us/windows/win32/api/fwpmu/nf-fwpmu-fwpmenginesetoption0)。公共观察端点使用 [Cloudflare 官方列出的地址](https://developers.cloudflare.com/1.1.1.1/ip-addresses/)，查询仅含随机 `.invalid` 标签。

## 尚未覆盖的边界

- 公网 IPv6 保留未验收。实际宿主复核有 IPv6 默认路由；联网 Windows Sandbox 没有 IPv6 默认路由，未限制基线返回网络不可达。不能把这种失败计作保护成功。用户已要求先完成其余 IPv4 工作；受管 IPv6 阻断和映射双栈的受控测试继续保留。
- 最终候选已不依赖调试回环例外；Windows 服务编排、长期运行和生产恢复仍未部署。文件通道只用于实验，不是生产网络内核，桌面保护尚未接入。
- 父程序、固定辅助程序、同名不同路径对照共三种临时 EXE 身份、x64 进程和既定调用以外，真实应用全部联网组件、跨架构及其他共享服务没有扩大声明。
- 用户另行明确授权的本轮一次来宾重启已执行，包 `.local/p0/sandbox/20261114-062459-aae4f3/` 的十二条父/辅助/端口规则跨重启及恢复共 39 条检查通过；该次授权已消耗。此结果不覆盖后加的六条 SID 规则跨重启，也不证明最早开机阶段。
- 冷启动最早阶段、完整网络切换/睡眠恢复及所有既有连接类型仍需对应证据。启动任务在 Windows 服务启动后执行，不等于最早内核启动阶段。

所有系统规则、临时身份、进程和文件 DACL、NRPT 和诊断采集的实验均只在来宾进行。宿主仅普通权限协议检查、只读核查和连接既定回环代理的限时中转；未加载驱动、安装商业 SDK、启用 TUN 或重启宿主。

## 复现与清理

```powershell
.\scripts\p0\build-lab.ps1
.\scripts\p0\build-transparent.ps1
.\scripts\p0\prepare-sandbox.ps1 -IncludeTransparent -PublicChecks -PublicNetwork -IPv4Only -ExpectedProxyIPv4 <已核验的代理出口>
.\scripts\p0\sandbox-lab.ps1 -Action Start -PublicNetwork
.\scripts\p0\start-batch-bridge.ps1
# 读取完整报告后，关闭本轮项目资源：
.\scripts\p0\stop-batch-bridge.ps1
.\scripts\p0\sandbox-lab.ps1 -Action Stop
```

默认准备模式仍关闭来宾网络。联网模式必须在准备与启动两处显式选择；清单须标记为受控公网验证，不自动重启或续期。公开 HTTPS 目标固定、验证证书、拒绝跳转，不导入宿主账户。

`guest-batch-reboot.ps1 -Action Prepare` 只安装并核对十二条实验规则、写恢复记录和安排来宾启动任务，不执行重启。`Restart` 动作另需显式单次授权开关，重复使用被拒绝；恢复工具依据固定身份、端口和工具摘要处理自己的规则，不能作为任意程序的高权限命令接口。
